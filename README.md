# MTV Россия — сайт-концепт

Адаптивный статический сайт MTV Россия с отдельными страницами, расширенной demo-CMS и кастомной страницей 404.

## Структура сайта

- `index.html` — главная
- `news.html` — новости
- `projects.html` — проекты
- `about.html` — о канале
- `contacts.html` — контакты
- `404.html` — страница ошибки 404
- `admin.html` — MTV Studio
- `style.css` — общая визуальная система
- `app.js` — общий клиентский рендеринг данных
- `admin.js` — логика Studio

Публичный дизайн сделан в современной editorial/TV эстетике: крупная типографика, тёмная база, кислотный акцент, сетки карточек, hover-эффекты и адаптивная мобильная навигация. Референс использован как визуальное направление, без 1:1 копирования чужой страницы.

## GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save** и дождитесь публикации.

GitHub Pages автоматически использует `404.html` для несуществующих адресов.

## MTV Studio

Откройте `admin.html`.

Демо-вход: `MTVA` / `MTVA`.

В Studio доступны:
- обзор со статистикой и быстрыми действиями;
- редактирование главного экрана;
- CRUD новостей: добавить, изменить, удалить, дублировать, скрыть/опубликовать;
- поиск по новостям;
- CRUD проектов и публикация/скрытие;
- редактирование страницы «О канале»;
- изменение email и Telegram-ссылок;
- управление демо-командой;
- переключение цветовой темы;
- экспорт JSON;
- импорт JSON;
- сброс demo-контента;
- очистка локальных данных;
- быстрые ссылки на предпросмотр.

Все изменения публичных страниц сохраняются в `localStorage` текущего браузера.

## Важно: это demo-CMS

Авторизация, роли и хранение контента работают в браузере и не являются production-защитой. Для настоящей CMS нужны server-side authentication, общая база данных, серверные права доступа и backend API.

Для автоматического импорта Telegram нужен серверный обработчик Telegram Bot API и хранение токенов в секретах хостинга. Не храните реальные пароли, токены и ключи в публичном HTML/JavaScript-репозитории.
